## 1. Introduction

Cloud computing is an important technology that supports the development of the Internet of Things (IoT) and smart manufacturing. It provides access to computing resources such as servers, storage, networks and software through the internet.

In manufacturing, machines and IoT devices can generate large amounts of data during production activities. Cloud computing allows this information to be stored, processed and accessed through online platforms. This helps manufacturers monitor production activities and make better decisions.

According to the National Institute of Standards and Technology (NIST), cloud computing provides convenient, on-demand network access to shared computing resources that can be rapidly allocated and released.

## 2. How Cloud Computing Works

Cloud computing works by connecting users and devices to remote computing resources through the internet.

In an IoT-based manufacturing environment, the general process involves the following steps:

1. Sensors and IoT devices collect data from machines and production equipment.
2. The collected data is transmitted through a communication network.
3. The data is sent to a cloud platform for storage and processing.
4. Cloud-based applications analyse and organise the collected information.
5. Operators and managers access the information through computers or mobile devices.
6. Based on the information, appropriate decisions can be made to improve production activities.

This process allows manufacturing data to be accessed without depending entirely on local computer storage.

## 3. Essential Characteristics of Cloud Computing

According to NIST, cloud computing has five essential characteristics.

**3.1 On-Demand Self-Service**

Users can access computing resources when needed without requiring direct interaction with the service provider for every request.

**3.2 Broad Network Access**

Cloud services can be accessed through networks using different devices, such as computers, laptops, tablets and smartphones.

**3.3 Resource Pooling**

Computing resources are shared among multiple users. These resources can include storage, processing power and network capacity.

**3.4 Rapid Elasticity**

Cloud resources can be increased or decreased according to user requirements. This allows organisations to adjust computing capacity when workloads change.

**3.5 Measured Service**

Cloud resource usage can be monitored and measured. This allows users to track their consumption of services such as storage, processing and network capacity.

## 4. Cloud Computing Service Models

Cloud computing provides three main service models.

**4.1 Infrastructure as a Service (IaaS)**

IaaS provides basic computing infrastructure such as virtual servers, storage and networking. Organisations can use these resources to build and manage their own systems.

**4.2 Platform as a Service (PaaS)**

PaaS provides a platform for developing, testing and managing applications without requiring users to manage the underlying infrastructure.

**4.3 Software as a Service (SaaS)**

SaaS provides software applications through the internet. Users can access these applications using a web browser or compatible device.

## 5. Cloud Deployment Models

Cloud computing can also be classified into four deployment models.

**5.1 Public Cloud**

Public cloud services are provided over the internet and shared among different users or organisations.

**5.2 Private Cloud**

Private cloud infrastructure is dedicated to a particular organisation. It provides greater control over the organisation's computing environment.

**5.3 Community Cloud**

Community cloud infrastructure is shared by organisations with similar requirements, such as security, policies or operational needs.

**5.4 Hybrid Cloud**

Hybrid cloud combines two or more different cloud infrastructures, such as private and public clouds. This allows organisations to use different environments according to their requirements.

## 6. Applications of Cloud Computing in Manufacturing

Cloud computing supports several activities in modern manufacturing.

**6.1 Production Data Management**

Manufacturers can store production information in cloud-based systems. This makes it easier to organise, access and manage production records.

**6.2 Remote Machine Monitoring**

Cloud platforms allow operators and managers to access machine information remotely. This supports the monitoring of equipment performance and operating conditions.

**6.3 Inventory Management**

Cloud-based systems can help manufacturers manage inventory information, including stock levels, material availability and product movement.

**6.4 Data Analysis**

Production data stored in cloud platforms can be analysed to identify patterns, monitor performance and support operational decisions.

**6.5 Collaboration and Information Sharing**

Cloud computing allows different departments to access shared information. This can improve communication between production, maintenance, management and inventory teams.

## 7. Benefits of Cloud Computing in Smart Manufacturing

The implementation of cloud computing can provide several benefits:

- **Data accessibility:** Production information can be accessed through internet-connected devices.
- **Scalability:** Computing resources can be adjusted according to manufacturing requirements.
- **Cost flexibility:** Organisations can use cloud resources without necessarily purchasing and maintaining all computing infrastructure themselves.
- **Improved collaboration:** Shared information supports communication between departments.
- **Data management:** Cloud platforms provide centralised storage and management of production information.
- **Decision-making support:** Analysed data can help managers identify production issues and opportunities for improvement.

## 8. Challenges of Cloud Computing

Despite its benefits, cloud computing also presents several challenges.

**8.1 Data Security and Privacy**

Manufacturing data may contain confidential information. Organisations must implement suitable security measures to protect stored information and prevent unauthorised access.

**8.2 Internet Dependency**

Access to cloud services depends on network connectivity. Poor internet connections may affect access to information and cloud-based applications.

**8.3 Service Availability**

Cloud service interruptions may affect access to important manufacturing information. Organisations should consider backup and recovery arrangements.

**8.4 Implementation Costs**

Although cloud computing can reduce the need for certain physical infrastructure, subscription fees, data transfer and system integration may still involve costs.

**8.5 System Integration**

Connecting existing manufacturing equipment and software to cloud platforms may require technical adjustments and additional resources.

## 9. Conclusion

Cloud computing plays an important role in supporting IoT and smart manufacturing by providing computing resources, data storage and online applications. It allows manufacturing organisations to collect, store, process and access production information through connected systems.

Through its service models, deployment models and essential characteristics, cloud computing offers flexibility and scalability for different manufacturing requirements. Although challenges such as data security, internet dependency and system integration must be considered, cloud computing remains an important technology for developing connected and data-driven manufacturing environments.
