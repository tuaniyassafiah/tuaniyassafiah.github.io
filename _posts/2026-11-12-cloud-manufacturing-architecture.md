## 1. Introduction

Cloud Manufacturing is a service-oriented manufacturing model that integrates cloud computing with distributed manufacturing resources. It allows organisations to access manufacturing equipment, software, facilities, and technical capabilities through a shared digital platform.

To support these activities, a structured architecture is required to connect physical manufacturing resources with digital services. Cloud Manufacturing Architecture provides the framework for managing resources, processing information, coordinating manufacturing activities, and delivering services to users.

Although different Cloud Manufacturing models may use different architectural structures, a common approach is to organise the system into several functional layers.

## 2. Overview of Cloud Manufacturing Architecture

Cloud Manufacturing Architecture describes how manufacturing resources and digital technologies are organised within a cloud-based environment.

The architecture connects physical resources, communication technologies, cloud platforms, and service applications. Each component performs a specific function to ensure that manufacturing resources can be accessed and managed efficiently.

A simplified architecture can be divided into five functional layers:

1. Physical Resource Layer
2. Resource Access and Communication Layer
3. Virtualisation and Resource Management Layer
4. Cloud Service Layer
5. Application Layer

These layers work together to provide manufacturing services through a connected digital platform.

## 3. Main Layers of Cloud Manufacturing Architecture

### 3.1 Physical Resource Layer

The Physical Resource Layer represents the actual manufacturing resources available within factories and production facilities.

Examples include:

- CNC machines.
- Industrial robots.
- Production equipment.
- Assembly lines.
- Testing and inspection equipment.
- Manufacturing facilities and workshops.

These physical resources perform manufacturing activities such as machining, assembling, processing, and product inspection.

### 3.2 Resource Access and Communication Layer

The Resource Access and Communication Layer enables communication between physical manufacturing resources and the cloud platform.

It collects operational information and transfers data through communication networks. Technologies such as the Internet of Things (IoT), industrial sensors, gateways, and network communication systems can support this process.

This layer allows manufacturing equipment to exchange information with digital systems for monitoring and coordination.

### 3.3 Virtualisation and Resource Management Layer

The Virtualisation and Resource Management Layer represents physical manufacturing resources in a digital form.

Through virtualisation, manufacturing resources can be described, organised, and managed as digital resources. The platform can maintain information about resource availability, capabilities, performance, and operating conditions.

This layer helps manufacturers identify suitable resources and allocate them according to production requirements.

### 3.4 Cloud Service Layer

The Cloud Service Layer provides manufacturing capabilities as accessible digital services.

Examples include:

- Manufacturing-as-a-Service.
- Design and engineering services.
- Production planning services.
- Equipment monitoring services.
- Quality inspection services.
- Maintenance services.

Users can select the services required without necessarily owning all the physical resources involved.

### 3.5 Application Layer

The Application Layer is the user-facing layer that allows manufacturers and customers to interact with the Cloud Manufacturing platform.

It provides applications and interfaces for accessing manufacturing services, submitting production requirements, monitoring operations, and reviewing manufacturing information.

For example, a manufacturer may use a cloud application to request machining services from an external production facility.

## 4. Interaction Between the Layers

The five layers work together to support the delivery of manufacturing services.

First, physical resources perform manufacturing activities and generate operational data. The communication layer transfers this information to the cloud environment. The virtualisation and resource management layer then organises the resources into digital representations.

After that, the cloud service layer makes selected manufacturing capabilities available to users. Finally, the application layer allows users to request, access, and monitor the services.

This interaction creates a connected manufacturing environment where resources can be shared and coordinated across different locations.

## 5. Importance of Cloud Manufacturing Architecture

A structured architecture provides several advantages:

- **Resource integration:** Connects different manufacturing machines, equipment, and facilities.
- **Resource sharing:** Allows manufacturing capabilities to be accessed by multiple organisations.
- **Production flexibility:** Supports the selection of resources based on changing production requirements.
- **Information management:** Improves the collection, organisation, and exchange of manufacturing data.
- **Service accessibility:** Allows users to access manufacturing services through digital applications.
- **Operational coordination:** Supports collaboration between different manufacturing service providers.

## 6. Conclusion

Cloud Manufacturing Architecture provides an organised framework for integrating physical manufacturing resources with cloud-based services. Its functional layers support communication, resource virtualisation, service management, and user interaction. By connecting these layers, manufacturers can improve resource utilisation, information sharing, and production flexibility. Therefore, Cloud Manufacturing Architecture plays an important role in supporting the development of intelligent and interconnected manufacturing systems.
